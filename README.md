# MyQuran — Қуръон оятлари (сайт + надстройка Word)

Поиск аятов и вставка в документ: арабский текст (несколько мусхафов), переводы на
~70 языков, тафсиры, аъуза/басмала, ссылка `[يونس ١]`. Формат по умолчанию:

```
﴿…текст аята(ов) с номерами ۝١ … ۝٢﴾
«1. … 2. …» (Моида: 1-2).
```

Сайт: https://abdullohukr.github.io/quranuz/ — он же панель надстройки Word.

## Возможности

- **Поиск**: `2:255`, `2 30-37`, `Бақара 30-37`, `Al-Baqarah 255`, `البقرة ٥`, арабский текст
  с диакритикой или без (`قل اعوذ برب الناس`, `ٱلرَّحۡمَـٰنِ`), слова из любого выбранного
  перевода на любом языке. Shift+клик по результату расширяет диапазон.
- **Выбор слов**: протянуть мышью по словам или кликнуть первое, затем последнее слово.
- **Настройки (⚙)** сохраняются: язык интерфейса (22 языка, по умолчанию узбекский), мусхаф,
  «Таржима» — галочка + несколько переводов сразу, «Тафсир» — галочка + несколько тафсиров,
  скобки ﴿ ﴾, аъуза, басмала, `[سورة رقم]`, новый абзац в Word, шрифты и размеры.
- **Форматирование**: арабский текст жирный; перевод жирный, пояснения в `( )` и `[ ]`
  обычные, ссылка `(Сура: 1-2).` курсивом; у каждого языка свои кавычки и направление
  текста (арабский, урду, фарси — справа налево).
- **ⓘ информация о суре** (английский; узбекский — `web/data/surah_info/uz.json` в том же
  формате, что `en.json`).

## Данные

| Путь | Что это |
|---|---|
| `Quran.csv` | узбекские переводы и тафсиры (Алоуддин Мансур, Муҳаммад Содиқ, Муяссар, Мухтасар) |
| `tools/scrape_tafsir_one.py` | арабский текст с read.tafsir.one (668 страниц), без изменений |
| `tools/build_db.py`, `tools/verify.py` | `web/data/quran.json`, `data/Quran_tafsirone.csv`, проверки |
| `tools/scrape_qul.py`, `tools/build_qul.py` | импорт из **QUL** (qul.tarteel.ai, открытый проект Tarteel) |
| ветка **`qul-data`** → `library/` | все переводы, тафсиры и мусхафы QUL **в одной папке**: `library/<Язык>/translation - <Переводчик> (id).json`, `library/<Язык>/tafsir - <Автор> (id)/<сура>.json`, `library/Arabic (mushaf)/…`, `library/index.json` |
| `web/data/catalog.json` | список всего, что доступно в приложении |
| `web/fonts/` | Scheherazade New + шрифты мусхафов QUL, `MyQuran-fonts.zip` с установщиками |

Импорт QUL: изменение `tools/qul_run.json` в ветке запускает `.github/workflows/qul.yml`
(или Actions → «Import from QUL» → Run workflow). Используются только открытые страницы и API
QUL; ресурсы с пометкой © и узбекские ресурсы QUL пропускаются. Глиф-шрифты по страницам
(QPC V1/V2/V4) в Word работать не могут и не импортируются.

## Шрифты

Для правильного вида в Word шрифт мусхафа должен быть установлен на компьютере.
Архив `MyQuran-fonts.zip` (ссылка в ⚙) содержит все шрифты и установщики:
- **Windows**: `install-windows.bat` (без прав администратора) — или выделить файлы → «Установить»;
- **macOS**: `install-mac.command` (если macOS блокирует: правый клик → «Открыть») — или
  открыть файлы и нажать «Установить».

Текст tafsir.one показывает **Scheherazade New**; шрифты KFGQPC рассчитаны на другую кодировку
(для мусхафа «Quran Library — Hafs» приложение само выбирает его шрифт).

## Сайт и надстройка

- Сайт публикуется workflow-ом `.github/workflows/pages.yml` (Settings → Pages → Source:
  GitHub Actions). Локально: `cd web && python3 -m http.server`.
- Word: установить `addin/manifest.xml` (Mac: в папку
  `~/Library/Containers/com.microsoft.Word/Data/Documents/wef`; Windows: через общую папку
  «Каталоги надёжных надстроек»; Word Online: Вставка → Надстройки → Загрузить).
  Кнопка **MyQuran** появится на вкладке «Главная».
