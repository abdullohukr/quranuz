# quranuz — Қуръон оятлари (сайт + надстройка Word)

Поиск аятов (по номеру суры и аята, по названию суры, по арабскому тексту с диакритикой
или без неё, по тексту перевода) и вставка в документ в формате:

```
﴿…текст аята(ов) с номерами ۝١ … ۝٢﴾
«1. … 2. …» (Моида: 1-2).
```

## Структура

| Путь | Что это |
|---|---|
| `Quran.csv` | исходная таблица (переводы, тафсиры, названия сур) |
| `tools/tafsir_one_pages.json` | карта 668 страниц `read.tafsir.one/almuyassar#pg_1…#pg_668` |
| `tools/scrape_tafsir_one.py` | скачивает **только аяты** (без тафсира) со всех 668 страниц без изменений; убирает `﴿ ﴾` и `[سورة: …]`, оставляет ۞ ۩ ۜ и все знаки остановки; добавляет ` ۝N` как на сайте |
| `tools/build_db.py` | собирает базу: `data/Quran_tafsirone.csv` (та же таблица, что Quran.csv), `data/000_basmala.txt` (﷽), `data/quran_brackets.json` (﴿ ﴾), `web/data/*.json` |
| `tools/verify.py` | проверка: 6236 аятов, каждый кончается на ` ۝N`, нет `﴿﴾` и `[…: …]` |
| `web/` | сайт; он же — панель надстройки Word |
| `addin/manifest.xml` | манифест надстройки Word |

## Скачивание аятов с read.tafsir.one

Вариант 1 — на GitHub: **Actions → "Scrape ayahs from read.tafsir.one" → Run workflow**.
Скрипт скачает страницы 1–668, пересоберёт базу, проверит и закоммитит результат.

Вариант 2 — локально (нужен только Python 3):

```bash
python3 tools/scrape_tafsir_one.py      # → data/tafsir_one_ayahs.json
python3 tools/build_db.py               # → data/Quran_tafsirone.csv, web/data/...
python3 tools/verify.py
```

Пока аяты не скачаны, `web/data/quran.json` временно собран из колонки `quran_ar` в
`Quran.csv` (видно в настройках сайта: «Араб матни манбаси»).

## Сайт

Публикуется на GitHub Pages workflow-ом `.github/workflows/pages.yml`
(Settings → Pages → Source: **GitHub Actions**). Адрес: `https://abdullohukr.github.io/quranuz/`.
Локально: `cd web && python3 -m http.server` → http://localhost:8000.

На сайте «Қўйиш» копирует текст (HTML + обычный текст) — вставляйте куда угодно (Ctrl+V).

Поиск: `2:255`, `2 30-37`, `Бақара 30-37`, `моида 1`, `البقرة ٥`, `قل اعوذ برب الناس`,
`ٱلرَّحۡمَـٰنِ`, слова из узбекского перевода. Shift+клик по результату расширяет диапазон.
Клик по слову в аяте: 1-й клик — начало, 2-й — конец (вставятся только выбранные слова;
скобки ﴿ ﴾ ставятся вокруг выбранного).

Настройки (⚙): перевод по умолчанию (Алоуддин Мансур), добавлять ли перевод, скобки ﴿ ﴾,
**автоматически добавлять новый абзац** в Word, шрифт и размер арабского/узбекского текста.

## Надстройка Word

1. Сайт должен быть опубликован (см. выше).
2. Word (Windows/Mac): **Вставка → Надстройки → Мои надстройки → Загрузить мою надстройку**
   и выбрать `addin/manifest.xml`. Word в браузере: **Вставка → Надстройки → Загрузить**.
   Для организации — через Microsoft 365 admin center (Integrated apps).
3. На вкладке «Главная» появится кнопка **Қуръон → Оятлар**.

В Word арабский абзац вставляется справа налево (RTL), под ним — абзац с переводом.
### Шрифт

Текст tafsir.one (буква `ی`, открытые танвины `ࣰ ࣱ ࣲ`, знак `۝` + номер) правильно
показывает шрифт **Scheherazade New** (SIL, лицензия OFL). Установите его в систему:
[Regular](web/fonts/ScheherazadeNew-Regular.ttf), [Bold](web/fonts/ScheherazadeNew-Bold.ttf)
(или ссылки в ⚙ настройках панели). Подходит также **Amiri Quran**.

Шрифты **KFGQPC HAFS Uthmanic Script** рассчитаны на другую кодировку: `ی` в середине слова
у них превращается в чёрную точку, а `۝١` — в двойной кружок. Для этого текста их не используйте.
Панель и сайт используют встроенный Scheherazade New, установка нужна только для Word.
