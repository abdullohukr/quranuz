Khatt al-Quran

Ўрнатувчи бир марта ишга туширилади ва қуйидагиларни ўрнатади: барча шрифтлар (мусҳафлар ва QPC V1/V2/V4 саҳифа шрифтлари) (Mac: ~/Library/Fonts, Windows: алоҳида Khatt al-Quran папкаси), ва Word учун Khatt al-Quran қўшимчаси. Администратор ҳуқуқи керак эмас.

Установщик запускается один раз и ставит: все шрифты (мусхафы и страничные шрифты QPC V1/V2/V4) (Mac: ~/Library/Fonts, Windows: отдельная папка Khatt al-Quran), и надстройку Khatt al-Quran для Word. Права администратора не нужны.

Run the installer once. It installs all fonts (mushaf fonts and QPC V1/V2/V4 page fonts) (Mac: ~/Library/Fonts, Windows: a separate Khatt al-Quran folder), and the Khatt al-Quran add-in for Word. No administrator rights needed.

Windows 10 / 11

  1. MyQuran-Install-Windows.bat ни юклаб олинг ва икки марта босинг («Windows protected your PC» чиқса: More info → Run anyway).
  2. Ёки PowerShell'ни очиб, қуйидаги буйруқни қўйинг:
  1. Скачайте MyQuran-Install-Windows.bat и запустите двойным щелчком (если появится «Windows protected your PC»: Подробнее → Выполнить в любом случае).
  2. Или откройте PowerShell и вставьте команду:
  1. Download MyQuran-Install-Windows.bat and double-click it (if “Windows protected your PC” appears: More info → Run anyway).
  2. Or open PowerShell and paste:
irm https://quran.abdulloh.org/win.txt | iex

Browser (Chrome, Edge, Firefox)

Оятни исталган сайтдаги матн майдонига қўйиш: Gmail, форумлар, ижтимоий тармоқлар, CMS. Khatt al-Quran ён панелда очилади; майдонда ўнг тугма → «Қуръон оятини шу ерга қўйиш». Google Docs'да «Қўйиш»дан кейин Ctrl+V босинг.

Вставка аята в любое поле ввода на сайтах: Gmail, форумы, соцсети, CMS. Khatt al-Quran открывается в боковой панели; в поле — правая кнопка → «Вставить аят Корана сюда». В Google Docs после «Вставить» нажмите Ctrl+V.

Insert an ayah into any text field on the web: Gmail, forums, social networks, CMSs. Khatt al-Quran opens in the side panel; in a field, right-click → “Insert a Quran ayah here”. In Google Docs press Ctrl+V after “Insert”.

  1. Chrome / Edge: khatt-al-quran-chrome.zip ни юклаб, очинг (unzip). chrome://extensions (Edge: edge://extensions) → «Developer mode» → «Load unpacked» → очилган папка.
  2. Firefox: khatt-al-quran-firefox.zip → about:debugging → «This Firefox» → «Load Temporary Add-on» → zip файл.
  1. Chrome / Edge: скачайте и распакуйте khatt-al-quran-chrome.zip. chrome://extensions (Edge: edge://extensions) → «Режим разработчика» → «Загрузить распакованное» → распакованная папка.
  2. Firefox: khatt-al-quran-firefox.zip → about:debugging → «Этот Firefox» → «Загрузить временное дополнение» → zip-файл.
  1. Chrome / Edge: download and unzip khatt-al-quran-chrome.zip. chrome://extensions (Edge: edge://extensions) → “Developer mode” → “Load unpacked” → the unzipped folder.
  2. Firefox: khatt-al-quran-firefox.zip → about:debugging → “This Firefox” → “Load Temporary Add-on” → the zip file.

Google Docs

Оят, таржима ва тафсир ҳужжатга форматлари билан қўйилади (араб матни — Scheherazade New шрифтида).

Аят, перевод и тафсир вставляются в документ с форматированием (арабский текст — шрифтом Scheherazade New).

The ayah, translation and tafsir go into the document with their formatting (the Arabic text in Scheherazade New).

  1. khatt-al-quran-google-docs.zip ни юклаб, очинг.
  2. Ҳужжатда: «Кенгайтмалар → Apps Script». Code.gs ўрнига шу файлни қўйинг; «+ → HTML» — номи Sidebar, Sidebar.htmlни қўйинг; «Лойиҳа созламалари → appsscript.json'ни кўрсатиш» — appsscript.jsonни қўйинг. Сақланг.
  3. Ҳужжатни янгиланг: «Кенгайтмалар → Khatt al-Quran».
  1. Скачайте и распакуйте khatt-al-quran-google-docs.zip.
  2. В документе: «Расширения → Apps Script». Замените Code.gs этим файлом; «+ → HTML» с именем Sidebar — вставьте Sidebar.html; «Настройки проекта → Показывать appsscript.json» — вставьте appsscript.json. Сохраните.
  3. Обновите документ: «Расширения → Khatt al-Quran».
  1. Download and unzip khatt-al-quran-google-docs.zip.
  2. In the document: “Extensions → Apps Script”. Replace Code.gs with this file; “+ → HTML” named Sidebar — paste Sidebar.html; “Project Settings → Show appsscript.json” — paste appsscript.json. Save.
  3. Reload the document: “Extensions → Khatt al-Quran”.

WordPress

«Қуръон ояти» блоки ва классик муҳаррирдаги «Ayah» тугмаси. Натижа мақолада оддий HTML бўлиб сақланади, араб шрифти плагин ичида.

Блок «Аят Корана» и кнопка «Ayah» в классическом редакторе. Результат сохраняется в записи обычным HTML, арабский шрифт — внутри плагина.

A “Quran ayah” block and an “Ayah” button in the classic editor. The result is saved in the post as plain HTML; the Arabic font comes with the plugin.

  1. khatt-al-quran-wordpress.zip → «Плагинлар → Янгисини қўшиш → Плагинни юклаш» → «Ўрнатиш» → «Фаоллаштириш».
  1. khatt-al-quran-wordpress.zip → «Плагины → Добавить новый → Загрузить плагин» → «Установить» → «Активировать».
  1. khatt-al-quran-wordpress.zip → “Plugins → Add New → Upload Plugin” → “Install” → “Activate”.
